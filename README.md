# 구미시 대피소 안내 웹 프로젝트

Flask 서버와 티맵 API를 사용하는 대피소 안내 프로토타입입니다. 사용자의 현재 위치를 받아 가까운 대피소를 계산하고, 관리자 승인 현재 침수구역 또는 사용자가 선택한 실제 침수흔적·50년 빈도 SHP 구역과 티맵 경로가 겹치면 안전 경유지를 추가해 재탐색합니다.

우회 후보는 티맵의 실제 차량·보행 경로로 다시 검증합니다. 완전 우회 경로가 없으면 침수구역 안에서 이동하는 예상 거리가 가장 짧은 경로를 선택하고, 최초 경로 대비 감소율을 화면에 표시합니다.

## 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

`.env`에 `TMAP_APP_KEY`, 침수흔적용 `SAFETYDATA_SERVICE_KEY`, 임시주거시설용
`SHELTERDATA_SERVICE_KEY`를 넣은 뒤 실행합니다.

```bash
flask --app app run --debug
```

브라우저에서 `http://127.0.0.1:5000`을 열면 됩니다.

## 위치 신고

사용자 화면에서 `현재 위치`를 GPS로 확인하면 `현재 위치 신고` 버튼이
활성화됩니다. 신고 좌표, GPS 정확도, 선택 메모는 SQLite
`data/reports.sqlite3`에 저장됩니다. `구미역 기준` 데모 좌표는 신고할 수
없으며, 서버는 구미시 인근 범위를 벗어난 좌표를 거부합니다.

관리자 지도는 `http://127.0.0.1:5000/admin/reports`에서 확인합니다. 신고
마커와 최신순 목록이 연동되며 새로고침 버튼으로 신규 신고를 불러옵니다. 관리자가
`침수 승인`을 누르면 신고 좌표를 중심으로 실제 반경 40m의 실시간 침수구역이
생성됩니다. `현재 침수`는 별도 스위치 없이 항상 지도와 목록에 표시하고 대피소
추천 및 차량·도보 우회 판정에도 포함합니다. 15초마다
승인·해제 상태를 갱신하며, 관리자가 `침수 해제`를 누르면 활성 구역에서
제거되지만 신고·승인·해제 시각과 좌표는 이력으로 계속 보존됩니다.

관리자 화면에서는 상태별 신고 필터와 신고·승인·해제 일시를 확인할 수 있습니다.
`지도에서 침수 추가`를 누른 뒤 지도에서 지점을 선택하면 좌표와 선택 메모를
확인하고 즉시 현재 침수구역으로 등록할 수 있습니다. 관리자 직접 등록 건도 반경
40m 구역으로 생성되며 `관리자 직접 추가` 필터와 데이터 구분으로 식별됩니다.
`Excel 내보내기`는 승인된 현재 침수 및 해제된 침수 이력을 한국시간 기준 연도,
날짜, 시간, 위도, 경도 등의 열로 구성한 `.xlsx` 파일로 내려받습니다. 승인 대기
신고는 확정 침수 이력과 Excel에서 제외됩니다.

데모용 현재 침수구역 15개는 공식 실제 침수흔적 `history.wkb` 내부에서 추출한
고정 좌표를 사용합니다. 일반 신고와 혼동되지 않도록 지도·관리자·Excel에서
`데모`로 표시하며 주황색 40m 원으로 그립니다. 다음 명령은 없는 샘플만 추가하므로
반복 실행해도 중복되지 않습니다.

```bash
python scripts/seed_demo_flood_reports.py
```

샘플도 관리자 화면에서 개별적으로 `침수 해제`할 수 있으며, 해제 후에는 이력으로
남고 시드 스크립트를 다시 실행해도 자동 재활성화되지 않습니다.

현재 관리자 페이지에는 로그인 기능이 없으므로 외부 공개 전에 인증과 접근 제어를
추가해야 합니다.

## 데이터

대피소는 재난안전데이터 공유 플랫폼의 `행정안전부_이재민 임시주거시설`
API에서 지역코드가 구미시 `47190`으로 시작하는 항목만 추출한
`data/shelters.gumi.json`을 사용합니다. 정확한 API는 `DSSP-IF-10945`이며,
별도의 이용신청이 승인된 서비스 키가 필요합니다. 2026-09-30 조회 기준 공식
구미시 이재민 임시주거시설 131곳이 저장되어 있으며 운동장 데이터는 포함하지
않습니다.

사용자 화면은 관리자 승인 신고를 SQLite에서 읽어 반경 40m 원형 폴리곤으로
변환한 `현재 침수`를 항상 표시합니다. `침수 위험지역`을 켜면 행정안전부
침수흔적도 API의 구미시 2012·2018년 실제 이력만 표시 및 우회 판정에
추가합니다. 별도 `50년 빈도`를 켜면 사용자가 제공한 지방하천 하천범람지도와
도시침수지도 SHP의 변환 결과만 표시 및 우회 판정에 추가합니다.

- `data/flood_maps/river`: 지방하천 하천범람지도 원본
- `data/flood_maps/urban`: 도시침수지도 원본
- `data/flood_maps/processed`: 서버 판정용 WKB와 지도 표시용 GeoJSON
- `data/reports.sqlite3`: 사용자 위치 신고 저장소(최초 신고/조회 시 자동 생성)

공식 API에서 실제 침수흔적을 갱신하려면 다음 명령을 실행합니다.

```bash
python scripts/fetch_recent_flood_traces.py
```

공식 API에서 구미시 이재민 임시주거시설을 갱신하려면 다음 명령을 실행합니다.

```bash
python scripts/fetch_gumi_shelters.py
```

API의 Web Mercator 좌표는 전처리 과정에서 티맵과 같은 `EPSG:4326`으로 변환됩니다. 서버는 정밀 WKB로 교차 여부를 판정하고, 브라우저에는 성능을 위해 단순화된 GeoJSON을 전달합니다. 50년 빈도 버튼은 사용자가 제공한 SHP에서 변환한 `river.wkb`와 `urban.wkb`만 사용합니다.

2026-09-30 API 조회 기준으로 구미시 등록 자료는 2012년 22건과 2018년 2건이며, 2021~2025년 등록 이력은 0건입니다. 이 24건의 실제 침수흔적만 `침수 위험지역`을 명시적으로 켰을 때 표시합니다.

CSV를 받았다면 다음처럼 앱 JSON 형식으로 변환할 수 있습니다.

```bash
python scripts/import_shelters_csv.py path/to/shelters.csv --output data/shelters.gumi.json
```

## 참고한 API

- 티맵 JS SDK: `https://apis.openapi.sk.com/tmap/jsv2?version=1&appKey=...`
- 티맵 보행자 경로안내: `https://apis.openapi.sk.com/tmap/routes/pedestrian`
- 티맵 자동차 경로안내: `https://apis.openapi.sk.com/tmap/routes`
- 행정안전부 침수흔적도: 재난안전데이터 공유 플랫폼 `/V2/api/DSSP-IF-00117`
- 행정안전부 이재민 임시주거시설: 재난안전데이터 공유 플랫폼 `/V2/api/DSSP-IF-10945`

티맵 지도 SDK는 브라우저에서 appKey가 사용되므로, 운영 시 SK open API 콘솔에서 허용 도메인 제한을 걸어두는 것이 좋습니다.
